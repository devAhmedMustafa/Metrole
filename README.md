# Metrole

## What is it

Just a tool I wanna build to remove the headache of self-hosting

## How to use it

*Haven't decided yet but...*

1. Add a docker compose file. ``metrole -root={PROJECT_PATH}``
2. Gonna open a menu for other options like:-

   - CPU and Memory limits
   - Domain name
3. Click start and it's gonna do the rest for you. It will pull the image, create the container, and set up the domain name for you.

## 3rd party communication

Via REST on port 2412
